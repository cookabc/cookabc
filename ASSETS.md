## Local Observatory / v2

`preview-v2.html` is the complete visual study. `README.v2.md` is the proposed GitHub release draft, not the published README. All v2 artwork is rendered from the local composition by `tools/export_v2.mjs` and the zero-dependency CDP helper from `033_zcode-inspector`. The exporter starts its own local source and temporary-document servers, waits for every image to decode, and exports each variant from a unique page to prevent navigation-cache mixing.

- `assets/v2/observatory-hero-{light,dark}{,-mobile}.svg`: static first frame plus one native SMIL scanning line. The scan respects reduced-motion preferences. Product imagery is rasterized; display and instrument lettering remain self-contained in the image. Mobile artwork is composed at 390 CSS pixels and exported at 2x resolution.
- `assets/v2/observatory-{observe,record,understand}-*.webp`: responsive scene artwork. Observe has light and dark variants; Record and Understand intentionally keep their material surfaces in both themes. Functional links remain real README links, not text pretending to be buttons inside an image.
- `assets/v2/fonts/bricolage.ttf` and `bricolage-OFL.txt`: Bricolage Grotesque, from `google/fonts/ofl/bricolagegrotesque`. Ark Pixel is retained for instrument annotations under `assets/ArkPixel-OFL.txt`.
- Record uses `033_zcode-inspector/docs/images/all-tools.png`, the actual Agent Inspector archive. The earlier decorative `319` count was removed because a transient local session count is not a durable personal achievement.
- The `LOCAL` lettering in Record is a decorative background layer, explicitly hidden from accessibility APIs in the HTML study.

Regenerate with `tools/export_v2.mjs` using Node 24.22.1; no separately started asset server is required. `tools/check_assets.py` validates SVG timelines recursively, including v2.
