# Surface brief: GitHub profile README

Scope: the public profile README (English + 简体中文), Experience mode — the work leads. Visitors are developers and designers deciding which of two projects to open. Constraints: GitHub Markdown/HTML subset, images only for expression, shared artwork across both editions, real links stay text.

## Direction contract

THESIS: A two-ink risograph proof sheet. Both projects are about telling things apart (Kachi: a word and its twin; Wayseeker: a habit and the tool that replaces it), so the profile is printed in exactly two plates. Refuses the category default: avatar banner, stats cards, badge rows, four equal project cards.

OWN-WORLD: Uncoated white stock (dark: black stock with screen-printed inks). Plate A blue, Plate B fluorescent red, overprint where they cross; nothing else is coloured except real screenshots. Archivo at its narrowest, heaviest cut as poster wood-type; Fragment Mono for numbers; Ark Pixel for printer's annotations. Crop marks and registration targets are functional furniture.

STORY: The visitor learns the one idea, sees each product's mechanism performed in its own words, then sees the real interface, then clicks Play / Browse.

FIRST VIEWPORT: Full-width masthead: “cookabc” at ~60% of the width in two misregistered plates that slide into near-register once; one line beneath; printer's slug in the margins. The project jump links sit directly under it.
